## Features

- 🌍 **1,000+ sites supported** - YouTube, TikTok, Instagram, Facebook, X/Twitter, and everything `yt-dlp` supports.
- 🎬 **Up to 8K video resolution** - Automatic format matching, MP4/MKV extraction, and smart merging.
- 🎵 **Pristine Audio extraction** - Direct MP3/M4A extraction with embedded ID3 metadata and cover art.
- ⚡ **Aria2c Multi-Threading** - Segmented download acceleration that saturates your bandwidth.
- 📋 **Zero-click clipboard monitor** - Copy a link anywhere, Savitar catches it instantly.
- 📁 **Playlist Mastery** - Download entire YouTube channels or playlists with a single click.
- 🛠 **Smart Backend** - Automatic updates for engines (`yt-dlp`, `ffmpeg`, `aria2c`) to keep sites working.
- 🎨 **Beautiful UI** - Clean Light/Dark themes, responsive WebView2 engine, absolutely zero clutter.
- 🚫 **No ads. No tracking. No limits.** - 100% free software. No installers bundled with adware.

## Install

1. Download the latest Setup from [**Releases**](https://github.com/kamstackbuild/Savitar-Desktop/releases/latest).
2. Run `Savitar-Setup-v1.0.0.exe`. It automatically installs all dependencies (including WebView2 and VC++ redistributables).
3. Open Savitar, paste a link, and hit **Download**.

> **Note:** Savitar is closed-source freeware. The installer provided here is the only official, safe source.

## Why Savitar?

Most desktop downloaders are packed with adware, artificial speed limits, or require paid upgrades for 4K. Savitar is built on the same battle-tested engine family used by the best open-source tools (`yt-dlp` + `FFmpeg` + `aria2c`), wrapped in a blazing fast, natively-compiled Windows desktop app with zero ads and zero cost.

## FAQ

**Videos are failing to download?**
Video platforms frequently update their code to block downloaders. Go to Settings > **Engines** and click "Update All". Savitar will pull the latest backend extractors instantly.

**Where do files go?**
By default, files go to your `Downloads/Savitar` folder. You can change this globally in the Settings menu or pick a custom folder per download.

**Is it safe?**
100% safe. Savitar runs entirely locally on your PC. It makes no analytics calls, has no ads, and the only network connections it makes are to download your media or check GitHub for engine updates.
