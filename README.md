## ⚡ Overview

**Savitar** is a high-performance desktop media downloader engineered for speed and simplicity. Powered by a multi-threaded segmented download engine and universal extractor backend, Savitar allows you to download videos, playlists, audio streams, and media clips from over 1,000+ websites at maximum bandwidth.

---

## 🚀 Key Features

- **⚡ Multi-Threaded Acceleration:** Segmented parallel downloading via bundled high-speed engine for maximum throughput.
- **🌐 1,000+ Platforms Supported:** Full support for YouTube (up to 4K / 8K 60fps), TikTok (no watermark), Instagram (Reels, Posts, Stories), Facebook, Twitter/X, Reddit, Vimeo, SoundCloud, and more.
- **🎵 Audio Extraction:** One-click conversion to high-bitrate MP3, M4A, or WAV with automatic ID3 metadata and album thumbnail embedding.
- **📦 100% Offline Standalone Installer:** Zero external dependencies needed. Bundles offline Microsoft Edge WebView2 and Visual C++ runtimes so it runs on fresh Windows installations out of the box.
- **🖥️ Clean Desktop UI:** Modern, lightweight interface with light and dark mode support.
- **🔒 Privacy First:** Runs completely locally on your system. No user tracking, no telemetry, no ad injection.

## 📥 Download & Install

1. Download the latest installer from the **[Releases Page](https://github.com/kamstackbuild/Savitar-Desktop/releases/latest)**:
   - **File:** `Savitar-Setup-v1.0.0.exe`
2. Run the installer and follow the setup wizard.
3. Launch **Savitar** from your Desktop or Start Menu.
